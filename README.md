🌐 Reconnect – Modern Social Media Platform

Reconnect is a full-stack social media web application that enables users to connect, chat, and join video calls in real time.
It uses GetStream for scalable messaging & video infrastructure and DaisyUI for a clean modern UI.

🚀 Features

🔐 Secure User Authentication (Signup / Login)

💬 Real-time Messaging (powered by GetStream)

🎥 Video Calling & Live Sessions

👥 Channel-based Conversations

🟢 Online / Offline Presence

🎨 Modern UI with DaisyUI

📱 Fully Responsive Design

⚡ Fast & Scalable Backend

🛠 Tech Stack
🎨 Frontend

React.js

Tailwind CSS

DaisyUI

🔥 Backend

Node.js / Express 

REST APIs

JWT Authentication

💬 Messaging & Video

GetStream (Stream Chat & Stream Video SDK)

🗄 Database

MongoDB
